# Attendance Marker

Attendance Marker is a modern student productivity application that combines attendance management, syllabus tracking, exam planning, and GPA calculation into a single platform. Built with Google's Material 3 design principles, it is available as both an offline-first Progressive Web App (PWA) and a native Android application.

## Features

- Smart attendance tracking with Present, Absent, and No Class status
- Weekly timetable management
- Live 75% attendance calculator with attendance predictions
- Subject-wise attendance analytics
- Excluded date ranges for holidays and leave
- Syllabus progress tracker
- Exam countdown with urgency alerts
- SGPA & CGPA calculator (GGSIPU Ordinance 11)
- Offline-first data storage using Zustand and LocalStorage
- Responsive Material 3 inspired interface
- Native Android support using Capacitor

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS v4
- Zustand
- Framer Motion
- Capacitor
- Progressive Web App (PWA)
- Android (Gradle)

## Installation

## Project Goals

- Help students maintain attendance efficiently.
- Track syllabus completion throughout the semester.

- Calculate SGPA and CGPA accurately.
